# Architecture

FireSight AI follows a modular web architecture:

1. React dashboard for GIS visualization, analytics, alerts, and reporting.
2. API service layer with Axios and React Query caching.
3. FastAPI backend exposing weather, GIS, prediction, alert, and analytics resources.
4. Future ML services for vegetation indices, hotspot detection, and risk scoring.
5. Future data layer for satellite rasters, weather feeds, model outputs, and alert history.
